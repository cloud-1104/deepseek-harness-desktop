DeepSeek Harness 桌面版，双击启动，不需要终端，也不需要浏览器。

### 下载

- Windows 10/11 x64：`.exe` 安装程序
- macOS Apple Silicon：`-arm64.dmg`
- macOS Intel：`-x64.dmg`

装完即可使用，不需要另外安装 Node 或其他运行时。首次启动请在界面的「模型」页面填入 API Key。

### 注意

安装包尚未签名。Windows 首次运行会出现 SmartScreen 提示，选择「更多信息 - 仍要运行」；macOS 需要在「系统设置 - 隐私与安全性」中点一次「仍要打开」。

会话与凭据保存在 `~/.dsh`，与命令行版本共用，两边可以看到同一份历史。
